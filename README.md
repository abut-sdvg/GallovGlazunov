
# LAVANDA

**Идея проекта:** Сайт для парикмахерской Lavanda, на котором представлена информация о мастерах, услугах и другие полезные сведения для клиентов.

## Стек технологий
* HTML
* CSS

## Запуск проекта
На текущем этапе разработки для запуска сайта необходимо:
1. Склонировать репозиторий к себе на компьютер:
   ```bash
   git clone <https://github.com/abut-sdvg/GallovGlazunov>
   ```
2. Открыть файл `index.html` в любом браузере.
